# 中文写作规范

## 总则

**默认中文。** 专业术语可附英文；句中不应残留**本可中译的普通英文词**。

判断依据是**通读全文后的语境理解**，不是死扣词表。

---

## 阅读笔记 vs 译文

| | reading_note.md | translation_zh.md |
|--|-----------------|-------------------|
| 专业术语 | 中文（English, 缩写） | 同样允许，后文可重复附英文 |
| 普通英文词 | 应中译 | 应中译（依全文判断） |
| 目标 | 讲解清晰 | 流畅、准确的中文译文 |

---

## 译文质量：两遍工作流（核心）

### 第一遍：生成完整译文

- 逐段忠实翻译，不省略
- 专业术语：**中文（English）** 括号可保留
- 专名、缩写、化学式、URL 保留

### 第二遍：通读审校（必做）

1. **先理解全文**：结合 `content.md`（及 SI）把握论证主线、术语体系、语气  
2. **再通读译文**：从头到尾读 `translation_zh.md`（及 `translation_si_zh.md`）  
3. **发现问题**：  
   - 句中是否残留**普通英文词**（形容词、副词、动词、日常短语）而未译？  
   - 该词在当前语境下是否实为**专业术语/专名**（可保留）？  
   - 中文是否通顺、准确、与原文一致？  
4. **修正**后再次快速通读确认

> 审校依赖**对全文的理解**，不是机械扫词。同一英文词在不同语境下处理可能不同。

## 参考：常见漏译普通词（非穷举）

以下为**经验参考**，便于审校时联想，**不是硬性禁词表**：

| 英文（示例） | 常见中文 |
|-------------|----------|
| challenging | 具有挑战性的 |
| entire | 整个 |
| arbitrary | 任意 |
| off-the-shelf | 现成 |
| understudied | 研究不足的 |
| dramatically / largely | 大幅 / 显著地 |
| non-trivial / trivial | 非平凡的 / 平凡的 |
| performance | 性能 |
| training / inference / sampling | 训练 / 推理 / 采样 |

遇到表中没有的词，仍按「是否普通词汇、是否应中译」自行判断。

## 可以保留英文

- **章节 / 小节标题**：中文译名后括号附原文标题，便于对照 PDF  
  - 例：`## 1 引言（Introduction）`、`### 2.1 数据表示（Data Representation）`  
  - 各级标题（`##` / `###` / `####`）均适用；图注、表注标题同理，如 `### 图 1. ……（Figure 1. ……）`
- **专业术语 + 括号英文**：基序（motif）、骨架（scaffold）、图神经网络（GNN）
- 缩写、人名、期刊、软件、数据集
- 化学式、变量、URL、算法函数名

**标题中的英文括号是对照注释，不算「漏译普通词」。**

## 反例与正例

**漏译普通词（错误）**：
> 扩展 **arbitrary** 生成模型 **dramatically** 优于 **off-the-shelf** 基线。

**正确**：
> 扩展**任意**生成模型**大幅**优于**现成**基线。

**专业术语（正确）**：
> 称为 **基序（motif）**……使用 **骨架（scaffold）** 约束时……

**章节标题（正确，便于对照）**：
> ## 3 方法（Methods）  
> ### 3.1 训练流程（Training Procedure）
