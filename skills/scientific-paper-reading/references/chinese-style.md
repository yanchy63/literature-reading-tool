# 中文写作规范

`reading_note.md` 与 `translation_zh.md` 均面向中文读者。**禁止漏译普通英文词**；专业术语括号可保留。生成后须**通读审校**（见 `translation-chinese.mdc`）。

## 何时保留英文

| 保留 | 示例 |
|------|------|
| 首次定义的专业术语 | 杂化金属卤化物钙钛矿（Hybrid Metal-Halide Perovskite, **HMHP**） |
| 无简洁中文的通用缩写 | **CD**、**CPL**、**PLQE**、**SOC**、**TA**、**RP** |
| 人名、机构、期刊、软件名 | Nature, Gaussian, VASP |
| 化学式、变量符号 | AMX₃、Pb²⁺、g_lum、ε_L |
| 原文固定缩写后文可直接用 | HMHP、RP 相（首次已定义） |

## 禁止 / 应避免

- ❌ 句中随意夹英文普通词：~~thin film~~ → **薄膜**；~~high level~~ → **较高水平**；~~dark states~~（已定义后）→ **暗态**
- ❌ 可译词不译：~~ellipticity~~ → **椭圆率**；~~ground state bleach~~ → **基态漂白（GSB，首次）**
- ❌ 中英重复啰嗦：~~CD 圆二色性~~ → **圆二色性（CD）** 或 **CD**（后文）
- ❌ 整句英文或半英半中混杂：`160 nm 薄膜 CD ellipticity > 20°`  
  ✅ `160 nm 薄膜的 CD 椭圆率 > 20°`

## 良好示例（来自项目笔记）

**小节标题**（术语 + 英文 + 缩写，一次说清）：
> ### 杂化金属卤化物钙钛矿（Hybrid Metal-Halide Perovskite, HMHP）

**正文**（中文为主，缩写和符号保留）：
> 本文研究 **n = 1** 的 2D 层状相：**A₂PbI₄**，无机层为 **单层角共享 [PbI₄]²⁻**，两侧夹有机胺层。

**列表**（先中文，缩写括号一次）：
> - **圆二色性（CD）**：测量左、右圆偏振光吸收系数之差……

## 写作流程

1. **先写中文句子**，仅在首次引入术语时括号附英文
2. 后文统一用**中文译名或已定义缩写**
3. **通读全文后审校**：结合语境检查不必要的英文夹杂，不机械扫词

详见 `docs/CHINESE_STYLE.md`。
