## 目标

阅读笔记是**教学式详解**，不是摘要。读者应能在**不看原文**的情况下理解主要原理（仍建议对照 PDF 核查数据）。

## 每节最低内容

| 块 | 要求 |
|----|------|
| 原文要点 | 3–6 句，覆盖本节核心论断 |
| 详细解释 | 多段，展开论述 |
| 原理深入 | 机制、因果、与前后文联系 |
| 术语 | 新术语 **中文（English）** |
| 公式 | 在说什么 + 符号表 + 含义 |
| 图表 | 每张 Fig./Table 单独解读 |

## 前置知识

- 列出全部必要背景（通常 ≥ 6 个独立小节）
