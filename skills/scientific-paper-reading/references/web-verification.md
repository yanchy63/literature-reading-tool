# 静默网页校验

科研场景对**内容正确性**要求高。AI 在生成阅读笔记或答疑时，须**内部**使用网页搜索校验和补充知识，但**绝不向用户展示**搜索过程或来源。

## 何时必须搜索（内部）

- 解释专业术语、缩写、方法名前
- 涉及标准定义、物理/化学常数、通用原理时
- 对原文表述不确定、或需补充背景知识时
- 笔记「前置知识」章节涉及领域通识时
- **生成 `translation_zh.md` 前**，校验专业术语的标准中文译法

## 搜索方式（二选一，不对用户提及）

1. **Cursor 内置 WebSearch 工具**（对话中优先）
2. **项目脚本**（需 JSON 结果时）：
   ```bash
   python scripts/web_search.py -t "术语" --context "文献主题"
   python scripts/web_search.py -r "主题" --field "化学信息学"
   python scripts/web_search.py -q "具体查询"
   ```

## 信息优先级

1. **本地文献**（`output/`、`notes/`）— 论文具体内容、作者观点、实验数据的**唯一权威**
2. **网页搜索** — 通用定义、背景知识、标准概念，用于**校验正确性**和**拓宽理解**

若网页与文献冲突：**论文内表述以文献为准**；通用知识以权威来源为准。

## 对用户完全隐藏

- ❌ 不说「我搜索了」「根据网上资料」
- ❌ 不在阅读笔记中附 URL、网页引用
- ❌ 不在 `translation_zh.md` 中写「据网络/维基」等字样或 URL
- ❌ 不展示搜索关键词或结果列表
- ✅ 将校验后的知识**自然融入**笔记、译文与回答，如同已掌握
- ✅ 译文中直接使用确定的标准译名，全文术语一致

## 准确性要求

- 优先采纳：教材级定义、维基百科、Distill、Nature/ACS 综述、arXiv 等
- 多个来源一致时才 confidently 写入；存疑则标注「原文未明确说明」
- 不臆造数据、不编造文献外结论
