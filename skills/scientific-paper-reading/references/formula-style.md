# 阅读笔记中的公式写法（人类可读）

> AI 生成 `reading_note.md` 时必须遵循。笔记面向**人类在 Markdown 预览中阅读**，不是 LaTeX 论文排版。

## 禁止

- ❌ `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 包裹的 LaTeX 公式
- ❌ `\frac{}{}`、`\mathbf{}`、`\mathrel{+}=` 等 LaTeX 命令
- ❌ 大段未解释符号的公式堆砌

## 必须采用的可读写法

### 1. 简单公式 → 纯文本 + Unicode

用日常符号与 Unicode 数学字符，必要时用反引号包裹：

| 原文 LaTeX 风格 | 笔记中应写为 |
|----------------|-------------|
| `$G=(V,E)$` | G = (V, E)（图 G，顶点集 V，边集 E） |
| `$\alpha, \beta$` | α、β |
| `$x_i \in \mathbb{R}^3$` | x_i 为三维实数向量 |
| `$\leq, \geq$` | ≤、≥ |
| `$\sum_{i=1}^N$` | 对 i = 1, …, N 求和 |
| `$\partial L / \partial w$` | L 对 w 的偏导数 ∂L/∂w |

### 2. 复杂公式 → 「口语描述 + 符号表」

先用人话说明关系，再用表格列出符号，**不要**贴一整行 LaTeX：

```markdown
**公式含义**：编码器为每个原子 i 输出潜变量的均值 μ_i 和标准差 σ_i，
再从标准正态噪声 ε 采样得到 z_i（重参数化技巧）。

**符号说明**：
| 符号 | 含义 |
|------|------|
| z_i | 原子 i 的潜向量 |
| μ_i, σ_i | 编码器预测的高斯分布参数 |
| ε | 标准正态随机噪声 |
| ⊙ | 逐元素相乘 |
```

### 3. 多符号关系 → 结构化列表

```markdown
**体系四元组** (A, X, F, L)：
- **A**：各原子的类型编号
- **X**：各原子的三维笛卡尔坐标（单位 nm）
- **F**：分数坐标（晶体用；分子中为空）
- **L**：晶格矩阵（分子中为空）
```

### 4. 算法 / 多步推导 → 编号步骤（不用公式块）

```markdown
**Encoder 步骤**：
1. 原子类型 a_i → 嵌入向量 h_i
2. h_i 加上坐标 x_i 经线性层后的信息
3. …
4. 输出 μ_i 与 σ_i，采样 z_i = μ_i + σ_i × ε
```

## 公式解读区块的标准格式

每个含公式的段落，用以下结构（**不用 LaTeX**）：

```markdown
**公式解读**：
- **在说什么**：（一句话口语概括）
- **符号说明**：（表格或列表）
- **物理/化学/数学含义**：（为何成立、在方法中起什么作用）
```

## 自检

生成笔记后，全文搜索 `$`、`\(`、`\frac`、`\mathbf`——**应为零匹配**。若有，改写为上述可读形式。

## Word 导出（`export_notes_docx.py`）

导出 `.docx` 时会自动把纯文本公式整理成更适合阅读的形式：

- `g_abs`、`A_L`、`10^{-3}` → Word 原生下标/上标（Cambria Math）
- `(分子)/(分母)` 一类简单分式 → Word 公式分式（OMML）
- 残留 `$...$` / `\frac` / `\alpha` 等 → Unicode 可读式后再排版

仍以 Markdown 人类可读写法为准；Word 侧是展示增强，不替代笔记正文规范。
